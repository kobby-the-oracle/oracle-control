# Competitive landscape and evaluation plan

## Adjacent product categories
- Agent observability and tracing: framework traces, run inspection, prompt/tool metrics and evaluations.
- Cloud agent runtimes: managed identity, session state, policy integration and runtime telemetry.
- Cloud and enterprise observability: logs, traces, metrics, alerting and incident workflows.
- SIEM/SOAR: security event correlation, alert triage, response orchestration and case management.
- AI governance/security: inventories, policy controls, model risk and compliance workflows.

Examples to include in ongoing evaluations: Amazon Bedrock AgentCore, Langfuse, Arize AX, Datadog, Microsoft agent tooling, LangSmith and established SIEM/SOAR platforms.

## Competitive claims policy
Do not claim a capability is absent from a competitor without checking the current product, tier, deployment mode and integration coverage. Feature sets change quickly. Distinguish native functionality, partner integrations, custom engineering and roadmap claims.

## Bake-off scenarios
1. Reconstruct a suspected sensitive-data access event across agent runtime, cloud audit and identity systems.
2. Show the permission/approval state at event time, including changes and revocation.
3. Preserve source provenance, clock uncertainty, collection failures and evidence hashes.
4. Export an investigator-readable case package with evidence references and custody history.
5. Demonstrate private deployment, tenant isolation, key custody and network-egress controls.

## Evaluation dimensions
- Source breadth and connector reliability.
- Identity and authority context.
- Timeline accuracy and relationship confidence.
- Evidence preservation and verifiability.
- Collection-gap visibility.
- Investigation workflow and export quality.
- Deployment, privacy and security controls.
- Total cost and operator effort.

## Strategic caution
Customers may already combine an agent observability tool, cloud audit logs, SIEM and ticketing workflow. ORACLE CONTROL must prove that its independent forensic layer materially reduces investigation time, improves evidence quality or enables investigations they cannot currently complete.
